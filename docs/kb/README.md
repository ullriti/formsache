# Wissensbasis

Wie das System aufgebaut ist und wie man es betreibt. **Warum** eine
Entscheidung so gefallen ist, steht in den [ADRs](../architecture/).

| Dokument | Thema |
|-----|-------|
| [`00-overview.md`](00-overview.md) | Was das Projekt ist, für wen, in welchem Zusammenhang |
| [`01-architecture.md`](01-architecture.md) | Teile, Guard-Kette, Datenflüsse, Nähte |
| [`02-data-model.md`](02-data-model.md) | Datenmodell — Entwurfsentscheidungen und Tabellen |
| [`03-modules.md`](03-modules.md) | Module und Zuständigkeiten — wo liegt was |

| [`10-datenschutz.md`](10-datenschutz.md) | Verarbeitungsverzeichnis, Löschkonzept, technische Maßnahmen |

## Pflege

- Nach jeder inhaltlichen Änderung das betroffene Dokument mitziehen.
- Handlungswissen gehört hierher, Begründungen in einen ADR.
- Wissen gehört ins Repository, nicht in ein lokales Gedächtnis.
